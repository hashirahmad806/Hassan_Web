# DESIGN SYSTEM RULES

Treat the existing design system as the source of truth.

Before creating a new component:

1. Search for an existing component.
2. Reuse it if possible.
3. Extend it if appropriate.
4. Only create a new component when necessary.

Maintain consistency for:

- colors
- typography
- spacing
- buttons
- cards
- forms
- navigation
- containers
- borders
- radius
- shadows
- animations
- breakpoints

Never create duplicate components such as:

ButtonNew
ButtonFinal
Button2
CardNew
CardFinal

when an existing component can be reused.

Prefer reusable and composable components.
