# NEW FEATURE WORKFLOW

1. Understand the requested feature.

2. Inspect the existing project.

3. Identify:
   - affected components
   - affected pages
   - APIs
   - database models
   - existing reusable components

4. Determine whether existing functionality can be reused.

5. Create a concise implementation plan.

6. Implement the feature incrementally.

7. Validate the implementation.

8. Check for regressions.

9. Review:
   - architecture
   - UI/UX
   - accessibility
   - performance
   - security

10. Update project state if architectural decisions were made.

11. Report:
   - files changed
   - functionality added
   - validation performed
   - remaining issues
