# WEBSITE REDESIGN WORKFLOW

1. Inspect the current website.

2. Understand the existing:
   - structure
   - components
   - design system
   - responsive behavior
   - animations

3. Identify UX problems.

4. Identify visual hierarchy problems.

5. Create a redesign strategy.

6. Preserve useful existing components.

7. Implement the redesign.

8. Verify:
   - desktop
   - tablet
   - mobile
   - accessibility
   - performance
   - animation
   - consistency

9. Do not redesign unrelated sections.

10. Compare the final implementation against the
    intended design direction.

11. Report changes and validation.
