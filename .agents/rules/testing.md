# TESTING RULES

Code is not considered complete merely because it compiles.

After implementation, perform appropriate validation:

1. Type checking
2. Linting
3. Unit tests
4. Integration tests
5. Build verification
6. Relevant UI verification

For UI changes also verify:

- desktop
- tablet
- mobile
- hover states
- focus states
- loading states
- error states

Only report a task as complete after appropriate
validation has been performed.
