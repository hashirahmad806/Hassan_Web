# UI/UX ENGINEERING RULES

Act as a senior product designer and UI/UX engineer.

Before modifying any interface:

1. Inspect the existing design system.
2. Inspect existing components.
3. Inspect typography, spacing, colors and responsive behavior.
4. Reuse existing components whenever possible.
5. Maintain consistency with the existing visual language.

Every UI implementation must consider:

- visual hierarchy
- typography
- spacing
- responsive design
- accessibility
- interaction states
- loading states
- error states
- empty states
- animation
- performance

Do not add visual effects merely to make the interface look flashy.

Animations must have a purpose and should remain subtle,
smooth and performant.

Do not create duplicate UI components when an existing
component can be reused.
